
## 상세 설명 — Chrome (그대로 복붙)

```
화면을 캡처하는 순간, AI에 그대로 붙여넣을 컨텍스트 팩이 완성됩니다.
아이콘을 클릭하거나 Alt+Shift+V를 누르면 영역 캡처가 시작되고, 캡처·핀 메모·출처가
한 묶음으로 정리됩니다. 설명을 다시 쓸 필요가 없습니다.

✨ 이렇게 동작합니다
1️⃣ 캡처 — 영역·요소·문서·풀페이지 중 원하는 방식으로
2️⃣ 핀 메모 — 중요한 자리에 번호 핀을 찍고 한 줄 메모. 핀마다 "버그/참고"를 표시할 수 있습니다
3️⃣ 확인 — 무엇이 복사되는지 요약 카드(템플릿·핀 수·이미지·메모)로 먼저 보여줍니다
4️⃣ 전달 — AI 채팅에 붙여넣거나, "내 AI에 저장"으로 연결한 코딩 AI가 직접 불러오게 합니다

🆕 0.4.6 — 사람에게 친절해졌습니다
· 프롬프트가 짧아졌습니다. 기본은 주소 + 핀 메모 + 요청 한 줄. 브라우저·화면 크기·좌표 같은 상세 정보는
  "버그 리포트" 템플릿에서 버그 핀이 있을 때만 붙습니다.
· 복사한 뒤, 저장한 뒤에 다음에 할 일을 한 줄로 알려줍니다.
· "내 AI에 저장" 결과가 캡처 기록마다 배지(저장됨 / 실패 → 재시도)로 남습니다. 조용히 실패하지 않습니다.

🖊️ 그리기 도구 (0.4.3)
가리기·화살표·형광펜·자유선. 가리기는 픽셀을 완전히 덮는 방식이라 복원할 수 없습니다(모자이크·블러 없음).

🔗 코딩 AI 연동 (MCP)
"내 AI에 저장"한 캡처를 Claude Code·Cursor·Codex가 직접 불러옵니다. 설정에서 연결 토큰을 복사해
붙여넣으면 연결이 끝나고, "방금 캡처 분석해줘"라고 말하면 AI가 캡처·핀 메모·출처를 함께 가져갑니다.
연결 토큰으로 격리되어 내 캡처만 조회되며, 토큰은 언제든 재발급할 수 있습니다.

🔒 프라이버시 먼저
· 캡처와 핀 메모는 기본적으로 브라우저 안에만 남습니다.
· 서버 전송은 "내 AI에 저장"을 누를 때만, 그때도 캡처 이미지·페이지 주소·핀 메모·입력한 요청만 보냅니다.
· 공개 링크를 만들지 않습니다. 저장본은 연결 토큰을 가진 내 AI만 읽을 수 있고, 이미지는 약 5분짜리
  서명 주소로만 전달됩니다.
· 보관 기간은 1·7·30일 중 고르고, 확장에서 즉시 삭제할 수 있습니다. 즉시 삭제는 서버 저장소까지 지웁니다.
· 계정·로그인·추적 없음. 쿠키·다른 사이트 인증 정보·로컬 데이터는 전송하지 않습니다.
· 개인정보 처리방침: github.com/byh3071-cpu/SnapContext/blob/master/docs/PRIVACY.md

💡 이럴 때 씁니다
· 버그 화면을 설명 없이 AI에게 그대로 넘길 때
· 디자인 피드백을 화면 위 핀 메모로 정리해 전달할 때
· 긴 문서·페이지를 출처와 함께 한 장으로 남길 때

📸 캡처 4모드
· 영역 선택 / 요소 선택 / 문서 본문 / 풀페이지 스크롤 전체
· 버그 리포트 · 리팩토링 · 레퍼런스 템플릿 제공

⌨️ 단축키 (기본 4개)
Alt+Shift+V — 영역 캡처
Alt+Shift+E — 요소 캡처
Alt+Shift+M — 문서 본문 캡처
Alt+Shift+G — 풀페이지 캡처
PNG 복사는 브라우저 단축키 설정에서 직접 지정할 수 있습니다.

💬 의견을 들려주세요
문제가 있거나 바라는 기능이 있다면 리뷰보다 먼저 알려주세요. 다음 업데이트에 반영하겠습니다.
→ github.com/byh3071-cpu/SnapContext/issues
```

## Privacy practices 입력 기준 (0.4.2와 동일 — 데이터 흐름 변화 없음)

- 웹사이트 콘텐츠: 수집함 — 사용자가 명시적으로 저장한 캡처, 제목, 정리된 URL, 핀 메모, 요청
- 인증 정보: 연결 토큰을 전송함 — 서버 검증용, 로컬 저장, 서버에는 token 원문을 저장하지 않음
- 사용자 식별자: owner hash 가명 식별자를 처리함
- 데이터 사용: 제품 핵심 기능 제공, 사용자 지원, 보안·법적 대응
- 판매·광고·신용평가: 사용하지 않음
- 제3자 처리: Cloudflare 인프라, 사용자가 선택한 AI 도구·AI 제공자
- 보관: 1·7·30일 자동 삭제와 사용자 즉시 삭제
- 권한: `manifest.json` 0.4.6 권한 목록이 스토어에 등록된 0.3.0과 같은지 제출 킷에서 대조(변화 없으면 "권한 변화 없음")
