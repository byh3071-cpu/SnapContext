# Chrome Web Store 문구 — SnapContext 0.4.2

> 이 파일은 제출 준비용이다. 실제 스토어 입력과 제출은 사람 승인 뒤에 한다.

## 짧은 설명

화면을 캡처하고 핀 메모를 남겨 AI 채팅에 붙여넣거나, 내 코딩 AI가 비공개로 불러오게 저장합니다.

## 상세 설명

SnapContext는 웹 화면의 맥락을 AI에 정확히 전달하는 Chrome 사이드패널 도구입니다.

1. 화면·요소·문서·전체 페이지를 캡처합니다.
2. 중요한 위치에 번호 핀과 메모를 남깁니다.
3. PNG와 컨텍스트를 AI 채팅에 직접 붙여넣거나 `내 AI에 저장`합니다.
4. 연결한 Claude Code, Cursor, Codex에서 `snap_history`로 최근 캡처를 불러옵니다.

`내 AI에 저장`은 공개 공유 링크를 만들지 않습니다. 이미지, 페이지 주소, 핀 메모와 사용자가 입력한 요청은 사용자가 버튼을 누를 때만 Cloudflare 기반 서버로 전송됩니다. 저장 기간은 1일, 7일, 30일 중 선택할 수 있고 확장에서 즉시 삭제할 수 있습니다.

연결 토큰은 계정 대신 저장본을 구분하는 비밀 문자열이며 owner 가명 식별자 생성에 사용됩니다. 연결한 AI 도구와 사용자가 선택한 AI 제공자가 조회 데이터에 접근할 수 있습니다.

## Privacy practices 입력 기준

- 웹사이트 콘텐츠: 수집함 — 사용자가 명시적으로 저장한 캡처, 제목, 정리된 URL, 핀 메모, 요청
- 인증 정보: 연결 토큰을 전송함 — 서버 검증용, 로컬 저장, 서버에는 token 원문을 저장하지 않음
- 사용자 식별자: owner hash 가명 식별자를 처리함
- 데이터 사용: 제품 핵심 기능 제공, 사용자 지원, 보안·법적 대응
- 판매·광고·신용평가: 사용하지 않음
- 제3자 처리: Cloudflare 인프라, 사용자가 선택한 AI 도구·AI 제공자
- 보관: 1·7·30일 자동 삭제와 사용자 즉시 삭제
