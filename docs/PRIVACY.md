# SnapContext 개인정보처리방침

최종 수정일: 2026-08-05 (v0.4.2)

공개 URL: https://github.com/byh3071-cpu/SnapContext/blob/master/docs/PRIVACY.md

## 핵심 요약

- 캡처와 핀 메모는 기본적으로 브라우저의 로컬 저장소에 남습니다.
- 사용자가 `내 AI에 저장`을 누를 때만 선택한 캡처가 서버로 전송됩니다.
- 신규 저장에는 공개 공유 링크가 만들어지지 않습니다.
- 연결 토큰을 설정한 AI 도구와 사용자가 선택한 AI 제공자가 저장한 데이터에 접근할 수 있습니다.
- 저장 기간은 1일, 7일, 30일 중 고를 수 있고 사용자가 즉시 삭제할 수도 있습니다.

## 로컬에서 처리하는 데이터

SnapContext는 캡처 이미지, 핀 메모, 캡처 기록, 설정과 연결 토큰을 `chrome.storage.local` 등 브라우저의 로컬 저장소에 보관합니다. 연결 토큰은 기기 간 자동 동기화하지 않습니다.

PNG나 컨텍스트 프롬프트를 복사해 AI 채팅에 직접 붙여넣는 흐름은 SnapContext 서버에 저장하지 않습니다. 이 경우 붙여넣은 대상 서비스의 개인정보처리방침이 적용됩니다.

## `내 AI에 저장`할 때 전송하는 데이터

사용자가 저장을 명시적으로 승인하면 다음 데이터를 HTTPS로 Cloudflare 기반 서버에 전송합니다.

- 캡처 이미지
- 페이지 제목과 query·fragment를 제거한 페이지 주소
- 캡처 종류·시각·화면 크기
- 핀 번호와 메모
- 사용자가 고른 `AI가 할 일`과 입력한 `AI에게 원하는 것`
- owner 구분을 위한 연결 토큰

브라우저 쿠키, 로그인 세션, 다른 사이트의 인증 정보, 전체 디버그 로그, 프로젝트 설정은 저장 payload에 포함하지 않습니다. 페이지 URL의 username, password, query, fragment는 확장에서 전송 전에 제거하고 서버에서도 다시 검사합니다.

## 가명 식별자와 토큰

연결 토큰은 계정 로그인을 대신하는 비밀 문자열입니다. 서버는 요청을 검증할 때 토큰을 사용하고, 토큰의 SHA-256 hash를 `owner`라는 지속되는 가명 식별자로 캡처에 연결합니다. 따라서 SnapContext는 owner 가명 식별자를 처리합니다.

토큰 원문은 서버 저장 데이터에 넣지 않습니다. 토큰을 공유하면 상대방이 같은 owner의 캡처에 접근할 수 있으므로 비밀번호처럼 보관해야 합니다.

## AI 도구와 이미지 접근

연결한 Claude Code, Cursor, Codex 같은 AI 도구는 MCP를 통해 자기 owner의 캡처를 조회할 수 있습니다. 조회된 컨텍스트와 이미지는 사용자가 선택한 AI 제공자에게 처리될 수 있으며, 해당 제공자의 정책이 적용됩니다.

이미지는 약 5분 동안 유효한 서명 URL로 전달됩니다. 이 URL은 만료 전에는 URL을 가진 주체가 사용할 수 있는 bearer URL입니다. URL 전체가 Cloudflare 등 인프라의 요청 로그에 일시적으로 남을 가능성이 있습니다.

## 저장·삭제

- 사용자가 고른 1일, 7일, 30일이 지나면 접근을 차단하고 저장소 lifecycle에 따라 삭제합니다.
- 확장 프로그램의 `서버에 저장된 캡처` 목록에서 즉시 삭제할 수 있습니다.
- 즉시 삭제는 이미지·컨텍스트를 먼저 삭제한 뒤 목록 index를 삭제합니다. 일부 단계가 실패하면 성공으로 표시하지 않고 재시도 가능한 오류를 보여줍니다.

## 공개 링크와 이전 버전

0.4.2부터 신규 저장은 공개 링크를 만들지 않습니다. 0.4.4부터 이전 버전의 공개 경로(`/s` 공유 링크·서명 없는 `/i` 이미지 주소·구 `/upload`)는 **제거되어 410(영구 폐쇄)으로 응답합니다**. 이전 버전에서 만든 공유 링크는 더 이상 열리지 않습니다.

## 서비스 제공자와 운영자 접근

Cloudflare는 Workers, R2, D1을 통한 전송·저장 인프라 제공자입니다.

운영자용 admin 읽기 접근은 다음 목적으로만 제한합니다.

- 사용자가 요청한 지원
- 보안 사고 조사와 서비스 복구
- 법적 의무 이행

운영자는 일상적인 제품 분석이나 광고 목적으로 캡처 내용을 열람하지 않습니다. 애플리케이션 로그에는 토큰, owner hash, capture id, 파생 저장 key, 전체 요청 URL을 의도적으로 기록하지 않습니다.

## Chrome 권한 사용 목적

| 권한 | 목적 |
|---|---|
| sidePanel | 캡처와 AI 연결 UI 표시 |
| storage | 로컬 캡처 기록, 설정, 연결 토큰 저장 |
| scripting | 사용자가 요청한 요소·문서 영역 선택 |
| downloads | PNG 파일 저장 |
| tabs | 현재 탭의 제목·주소와 캡처 대상 확인 |
| windows | 캡처 저장 창 생성 |
| host_permissions (`<all_urls>`) | 사용자가 요청한 웹페이지에서 캡처와 요소 선택 실행 |

## 판매·광고

SnapContext는 캡처나 가명 식별자를 판매하지 않으며 광고 타게팅에 사용하지 않습니다.
