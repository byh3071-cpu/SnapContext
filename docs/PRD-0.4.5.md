# SnapContext 0.4.5 — 요청 폭주 방어를 Cloudflare 관문으로 승급

> 용어 한 줄 사전: **요청 횟수 제한** = 같은 사람(IP)이 짧은 시간에 서버를 두드릴 수 있는 횟수의 상한. **Cloudflare 관문 규칙** = 요청이 내 서버 코드에 닿기 **전에** Cloudflare가 문 앞에서 세우는 차단 규칙(공식 명칭 WAF Rate Limiting Rules).

## 1. 목적 한 줄

지금의 요청 횟수 제한은 "서버 안 임시 카운터"라 폭주를 실전에서 못 막는다(카운터가 여러 개로 쪼개지고 수시로 리셋됨). 이를 **Cloudflare 관문 규칙**으로 승급해 서버 비용(저장소 남용)과 토큰 발급 스팸을 문 앞에서 차단한다.

## 2. 이번 조사로 확정한 사실 (2026-08-18)

| # | 사실 | 함의 |
|---|---|---|
| 1 | [웹/외부] 관문 규칙은 **Cloudflare에 등록된 내 도메인에만** 걸 수 있다 (공식 문서: zone 레벨) | 지금 주소(`…workers.dev`)는 Cloudflare 소유 도메인이라 규칙을 못 검 → **커스텀 도메인 연결이 선행 조건** |
| 2 | [웹/외부] 무료 플랜: 규칙 **1개**, 식별 기준 2개(IP 등), 조건 필드는 경로(Path) 중심 | 규칙 1개에 보호 대상 경로들을 묶어 넣어야 함. 충분히 가능 |
| 3 | 위협모델 문서(0.4.4 이전 작성)의 보호 대상 "`/upload`"는 **0.4.4에서 폐쇄됨** | 현행 보호 대상으로 갱신: 저장 경로 **`/captures`**(저장소 비용 유발·1순위)와 토큰 발급 `/token`(스팸·2순위) |
| 4 | 현행 서버 안 카운터: 토큰 발급 분당 10회·저장 분당 20회 — 단 "서버 조각(isolate)당"이라 전역 상한이 아님(코드 주석에 명시된 수용 트레이드) | 관문 규칙이 전역 상한을 맡고, 기존 카운터는 2중 방어로 유지 |

## 3. 범위·리스크

| 구분 | 내용 |
|---|---|
| 범위 | ① 커스텀 도메인을 워커에 연결 ② 관문 규칙 1개 설정 ③ 확장·문서의 서버 주소 전환 ④ 편승: 감사 M1(문맥 데이터 조립을 안전한 방식으로 교체 — 코드 위생) |
| 안 하는 것 | 토큰 만료·무효화(→ 0.4.7) · 프롬프트 UX(→ 0.4.6) · 스토어 제출(0.4.6 후 일괄) |
| 리스크 1 | 도메인 연결·규칙 설정은 대시보드 작업 = **전부 사람 게이트**. 잘못 걸면 정상 사용자도 차단됨 → 한도값을 넉넉히 시작해 조이는 방향 |
| 리스크 2 | 주소 전환 시 구주소(workers.dev)를 열어두면 관문 우회로가 남고, 닫으면 구주소 사용자가 끊김 → 결정 D2 |
| 리스크 3 | 요한이 Cloudflare에 등록된 도메인이 없으면 도메인 등록(구매 또는 이전)부터 필요 → 결정 D1 |

## 4. 요한 결재 사항 (착수 전 3건)

## 7. 합격 기준

1. 새 주소에서 저장·목록·삭제·AI 불러오기 전부 정상 (0.4.4 스모크와 동일 항목).
2. 한도 초과 요청이 Cloudflare 문 앞에서 차단되는 것 실측 (연속 요청 실험).
3. 기존 검사 전체 통과 + M1 교체분 검사 추가.
4. D2에서 A 선택 시: 유예기간·폐쇄 시점이 로드맵에 기록됨.

## 8. 기술 부록 (구현 AI 전용)

- 선행 조건 확정 근거: WAF RL rules는 zone 레벨(https://developers.cloudflare.com/waf/rate-limiting-rules/ — Free 1 rule·2 characteristics·Path 필드). workers.dev는 사용자 zone이 아님 → [추론, 확실성 높음] 룰 부착 불가. Workers RL binding은 per-colo·permissive라 기각(token-threat-model.md §0.4.5 항 유지).
- 커스텀 도메인: `wrangler.jsonc` `routes` + Custom Domains(대시보드) 또는 `custom_domains = true` 패턴. workers.dev 폐쇄는 `workers_dev = false`(D2-A 확정 시, 유예 후).
- 관문 규칙 초안(무료 1룰): expression `http.request.uri.path in {"/captures" "/token"}` + method POST(무료 필드 제약 확인 — Path 외 필드 불가 시 Path만으로), characteristics: IP. action: block, 기간 최소 단위.
- 주소 전환 지점: `VITE_UPLOAD_ENDPOINT`(.env — 빌드타임 상수, troubleshooting/2026-08-17-dogfood-dist-local-endpoint.md 함정 주의)·MCP 안내문(ImageActions.ts 연결 안내 JSON)·docs(PRIVACY·README·CONTEXT-PACK-SPEC 내 URL)·`register-mcp.ps1`.
- M1: lib.ts:132 `parseSharedContext` v1 경로 + pack.ts:153 스프레드 → 명시 필드 조립(handoff-audit-0.4.4.md M1). test-first.
- 검증: 한도 실측은 새 주소로 연속 curl(문 앞 차단 = worker 로그 무기록, `wrangler tail`로 확인). CDN 캐시와 무관(우리 응답 no-store).
